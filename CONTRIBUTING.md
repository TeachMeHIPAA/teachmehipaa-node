# Contributing

## Generated and hand-written code

The library is a hand-written core plus a resource and model layer generated
from the vendored IR (ADR-0001).

| Path                                         | Origin                                                            |
| -------------------------------------------- | ----------------------------------------------------------------- |
| `src/core/`, `src/client.ts`, `src/index.ts` | Hand-written                                                      |
| `src/models/`, `src/resources/`              | Generated by `npm run generate`; do not edit                      |
| `scripts/generate.ts`, `scripts/generator/`  | The generator                                                     |
| `openapi/`                                   | Vendored from the monorepo; do not edit (see `openapi/README.md`) |

Every generated file starts with a "Generated from openapi/sdk-ir.json — do not
edit" banner. To change generated code, change the generator, or fix the IR
upstream in the monorepo's `tooling/sdk-ir` and re-vendor it.

## Regenerating

1. Copy `openapi.developer.json`, `sdk-ir.json` and `sdk-ir.schema.json` from
   one IR build into `openapi/`, and its `source.release` into
   `OPENAPI_VERSION`.
2. Run `npm run generate` (Node 22.18 or newer, which runs TypeScript
   directly). It validates the IR against its schema, then rewrites
   `src/models/` and `src/resources/`, deleting files the IR no longer
   produces.
3. Run `npm test`. The generated-surface test fails if the committed output
   differs from what the generator writes, or if any spec operation lacks
   exactly one public method.
